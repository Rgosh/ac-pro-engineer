# What the core does

`ac_core` is the shared engine under all three front ends — the terminal, the
in-game panel, RG Pro Engineer's window and Pro Launcher. **It computes; they
draw.** Every threshold, verdict and piece of analysis is here, once, so no two
screens can tell a driver two different things about the same lap.

| Page | What is on it |
|---|---|
| [The race engineer](engineer.md) | live advice, why it says it, how sure it is, and whether last time's fix worked |
| [Lap analysis](analysis.md) | corners, braking, the line in metres, the ideal lap, grip, shifts, slips, consistency |
| [Strategy](strategy.md) | fuel, the stint, tyre and brake life, cold pressures |
| [Drift and street runs](drift-and-street.md) | drift scoring and the coach, traffic runs, the engineer quiet while you slide |
| [Games](games.md) | Assetto Corsa and Competizione, and what each measures |
| [The network](network.md) | the frame, the whole session, finding each other |
| [For the launcher](launcher.md) | content, physics tuning, career and special events, fair grids, servers, replays |
